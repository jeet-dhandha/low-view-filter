# Low-View Filter for YouTube

Landing page and privacy policy for the **Low-View Filter for YouTube** Chrome extension.

- Site: https://jeet-dhandha.github.io/low-view-filter/
- Privacy policy: https://jeet-dhandha.github.io/low-view-filter/privacy.html

The extension hides old and low-view videos in YouTube search, home and Shorts, based on a
view floor and an upload cut-off you set once.

Not affiliated with YouTube or Google.
